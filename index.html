What it does

  • Erases the FRP partition on MediaTek and Qualcomm in the right mode
  • Flashes Samsung firmware and bundles; prints the PIT so you flash the right partitions
  • Activates offline with an Ed25519-signed key — no server, no account
  • Plug-and-play bundle on the way: single .exe + embedded Python, no Python install

What it doesn't do — stated plainly

  • No iPhone support. iPhone Activation Lock is server-side at Apple; no local tool removes it.
  • No Samsung one-click FRP erase. A locked Samsung bootloader only takes Samsung-signed images.
  • No universal Qualcomm loader — if auto-pick fails, you supply the loader for that chipset.
  • Drivers still need a one-time install. Windows has to trust them itself.

FAQ

Straight answers, no fine print tricks.

Is this legal?

Use it only on phones you own or are authorized to service — your own phone, a customer's phone in your shop with their permission, a device you bought second-hand. Removing a lock from a phone that isn't yours to service is not what this tool is for, and the responsibility is yours.

What phones does it work on?

Any Android phone with a MediaTek, Qualcomm, Samsung (Exynos/Snapdragon in Download mode), or Unisoc/SPD chipset — as long as you can get it into the right mode: BROM for MediaTek, EDL 9008 for Qualcomm, Download mode for Samsung, SPD download mode for Unisoc. There's no brand-by-brand model list because the chipset and mode are what decide it. iPhones are not supported at all.

Do I need drivers?

Yes — one time. Install UsbDk plus the driver for the chipset you're using (MediaTek VCOM, Qualcomm QDLoader 9008, Samsung via Zadig/libusb, or SPD drivers). If Windows refuses an unsigned driver, disable Driver Signature Enforcement for that install — it resets on reboot and the driver stays. The coming plug-and-play bundle removes the Python install, not the driver step.

Can it one-click erase FRP on Samsung?

No — and any tool that promises that without conditions is overselling. Samsung's locked bootloader only accepts Samsung-signed images, so the shop path is combination firmware: print the PIT in Phone Unlocker, flash the combination firmware for that exact model, use its ADB/OEM-unlock route, then flash stock back. Phone Unlocker does the detect, PIT, and flashing parts honestly and well.

What about Qualcomm loaders?

EDL needs a Firehose loader matched to the phone's chipset — there is no universal one. The tool tries its collection automatically first, which covers many phones. If that fails, find the loader for your chipset (from the firmware package or the community collection linked in the app) and pick it with Browse. Getting into EDL itself varies by phone: EDL cable, test points, or adb reboot edl if debugging was already on.
